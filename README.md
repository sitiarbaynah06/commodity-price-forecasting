# commodity-price-forecasting
Daily commodity price forecasting using Hybrid ARIMA-GARCH and LSTM models.
## 🗂️ Data

| Keterangan | Detail |
|---|---|
| Sumber data | Dinas Perdagangan dan Perindustrian Kota Depok |
| Periode |Jan 2023 - Des 2025 |
| Frekuensi | Harian |
| Variabel | Harga Komoditas Pangan di Beberapa Pasar Kota Depok |

## 🛠️ Metodologi

1. **Preprocessing** — pembersihan data, pengecekan missing value, uji stasioneritas (ADF Test)
2. **ARIMA-GARCH** — pemodelan komponen linear dan volatilitas (heteroskedastisitas)
3. **LSTM** — pemodelan residual/non-linear dari hasil ARIMA-GARCH
